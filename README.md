# 🎓 Scholarship Finder

An AI-built tool that helps students find scholarships they qualify for and generates application letters.

## About
Built during Hackathon Cybernauts. The whole project was created with the help of AI tools, from idea to working code.

Note: the scholarships in this demo are sample data, not real offers.

## Features
- Enter your marks, family income, field of study, and province
- See which scholarships you qualify for
- See what is missing for the "almost" matches
- Get a ready application letter and a list of documents to prepare

## Built With
- HTML, CSS, JavaScript
- AI tools include Claude and Gemma.
